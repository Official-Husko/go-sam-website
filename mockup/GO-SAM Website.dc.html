GO-SAM

A modern, cross-platform port of Steam Achievement Manager.

View and toggle achievements, and edit stats, for any game you own — by talking directly to your local Steam client, the same way a game itself would. Native on Windows and Linux, no .NET Framework required.

How it works

Talks to Steam like a game would

Instead of the public Steamworks SDK — which needs each game's own credentials — go-sam talks directly to your locally installed Steam client's native library, the same low-level approach the original SAM used. On Go, this happens without cgo, using purego to call the client library's functions directly.

1

Reads your owned-games list from the official Steam Web API.

2

Talks to your running Steam client through its native library — steamclient.dll on Windows, steamclient.so on Linux.

3

Parses the achievement and stat schema Steam already caches locally for each game you own.

Building from source

git clone https://github.com/Official-Husko/GO-SAM.git cd GO-SAM go build -o go-sam ./cmd/go-sam

Cross-compiling for Windows (from Linux/macOS)

Building the GUI requires cgo for Fyne's rendering, so you'll need a Windows C cross-compiler such as mingw-w64.

CGO_ENABLED=1 GOOS=windows GOARCH=amd64 CC=x86_64-w64-mingw32-gcc \ go build -o go-sam.exe ./cmd/go-sam

Usage & configuration

Just run the binary. This opens the Picker: a list of your owned games.

1

Run ./go-sam — the Picker opens, listing games you own.

2

First run: open Settings and paste in your Steam Web API key.

3

Pick a game to open its Manager window.

4

Inspect and edit that game's achievements and stats.

Good to know

Selecting a game spawns a separate short-lived process scoped to that one game — you'll see it appear as its own window. This mirrors how the original SAM's SAM.Game.exe worked, and is intentional: it's how Steam's client library expects to be told which game is active.

Disclaimer

This tool edits achievement and stat data your Steam account already has access to, exactly as the game itself would. It's meant for single-player, personal use — unlocking missed achievements, fixing corrupted stats, and similar. Some games track stats server-side for leaderboards or competitive features; editing those is between you and that game's own rules, and outside the scope of what this tool is for. Use it at your own risk.
